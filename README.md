# Python-Fundamentals

This repository contains practice projects created while learning Python programming.

## Projects

### 1. Student Management System

A simple student record program demonstrating:

* Variables and data types
* Lists and dictionaries
* Loops
* Conditional statements
* Functions
* Basic calculations
* Finding averages and top-performing students
* Pass/fail evaluation

### 2. Library Management System

A simple library program demonstrating Object-Oriented Programming concepts:

* Classes and objects
* Constructors
* Attributes and methods
* Inheritance
* Lists and dictionaries
* Loops and conditional statements
* Adding books and members
* Borrowing books

## Concepts Covered

* Python Data Types
* Lists & Dictionaries
* Loops
* Conditional Statements
* Functions
* Classes & Objects
* Inheritance
* Basic Problem Solving
